# nathanaelguitar.github.io

Personal project showcase for Nathanael Gill — ML and analytics engineering.

Static HTML/CSS/JS, no build step. `index.html` is self-contained apart from
Google Fonts. Served by GitHub Pages from the repository root.

The design is a lighting plot: each project is a numbered cue on a seamless
cyclorama that passes from blackout to full day. Public repositories are
"patched" (linked); private work is shown as an unpatched channel with no link.

Every figure on the page traces to a file in the repository it describes.
See `DESIGN.md` for the visual system and `PRODUCT.md` for the content record.
