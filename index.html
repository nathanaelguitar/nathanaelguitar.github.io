Cue 10

AetherChat

A private, local-first AI chat app that runs the model on your phone. Two full native codebases — SwiftUI on iOS, Kotlin and Jetpack Compose on Android — over a shared inference layer, with an optional Ktor proxy when you want a server.

Quantized GGUF weights run on-device through llama.cpp, so conversations never leave the handset. Above that sit a SQLite memory store with full-text recall, a ChatML prompt builder, web-search intent detection and ranking for questions the local model cannot answer from memory, title generation, and loop detection.

The Android port is not a wrapper. The domain layer is ported from the Swift source file for file, down to a JNI wrapper that builds llama.cpp for arm64 and loads both a language model and a vision projector.

VC Scout

My Cornell capstone: a valuation-scale model for unicorn companies. It predicts ln(valuation in $B) from publicly listed fields across 1,060 modeled companies, with the framing chosen specifically to avoid a bias the dataset invites.

Every row in the data already reached unicorn status, so this can never be a startup-success predictor. It is framed strictly as conditional-on-unicorn valuation scale. Funding efficiency was deliberately excluded as a feature because it contains the target.

Cue 40

Agent
Evaluation

An offline framework for measuring whether an AI discovery-call agent is any good, without putting it on a live phone line. Same scenarios, same objections, three different agent policies, paired comparison.

Eight to twelve canonical call scenarios run against a scripted baseline, a freeform LLM agent, and a guided LLM agent under a checklist and constraints. Scored on rubric quality and discovery coverage, then on behaviour: question ratio, objection resolution, and derailment rate. A PySpark job rolls conversational turns up into call-level features.

Cue 50

Recursive
Agent Memory

Agents forget everything between sessions. I extended the open-source OpenClaw agent codebase with memory that survives the run: SQLite for structured storage, embedding-based semantic search for retrieval, and time-aware context assembly.

The two halves matter separately. Structured storage answers what happened and when, which a vector index is bad at; embedding search answers what was this about, which a SQL predicate is bad at. Assembling both into a time-aware window is what lets an agent pull its own prior logs into a later run instead of starting cold.

Cue 70

Topic
Modelling

A 24-topic LDA model over the business descriptions of the middle 1,000 companies by market capitalisation, then tested against GICS to see how much of a standard industry taxonomy an unsupervised model recovers on its own.

Each company's cleaned description becomes a 24-element topic probability vector; each is hard-assigned to its dominant topic; topics are named from their top words rather than their arbitrary numbers; then the assignments are cross-tabulated against GICS groups in both directions. The result is a coherence score per industry — and the finding that most of the performance came from preprocessing, not from the algorithm.

Supply
Chain

Graduate optimization work: inventory levels tuned to maximise supply-chain efficiency, and production capacity allocated across competing products under constraint.

Two linked decision problems. The first asks how much to hold and when to reorder so that service level survives demand variability without financing dead stock. The second asks which products get scarce capacity when you cannot make everything, and what that choice costs in contribution margin. Python models alongside the Excel workbooks the decisions were presented in.
