Fine-Tuning Qwen3.6-27B on IBES Analyst Revisions: Separating Schema Compliance from Classification Performance

Nathanael Gill·Cornell MSBA·June 2026

Abstract

I investigate the effects of QLoRA fine-tuning on Qwen3.6-27B using analyst estimate-revision events from WRDS/IBES. I construct the dataset through a PySpark bronze-silver-gold pipeline and evaluate the resulting adapter against the base model on a 1,000-event holdout.

Fine-tuning improves accuracy from 0.449 to 1.000 and macro F1 from 0.541 to 1.000. However, error decomposition reveals that much of the improvement is attributable to structured-output compliance. The base model fails to produce parseable responses on 53.4% of events, despite correctly classifying all 447 positive and negative events for which it returns a direction.

I further compare adapters trained on 1k and 10k events. Both achieve perfect holdout accuracy, while the larger adapter performs worse on most of four public sentiment benchmarks. These results distinguish gains in task execution from evidence of improved financial reasoning or generalization.

1. Methodology

Each observation represents an analyst estimate-revision event. The model receives event-level information and produces a JSON object containing a directional classification (positive, neutral, negative) and a magnitude bucket.

I derive directional labels from changes in analyst consensus. Changes below a defined threshold receive a neutral label; otherwise, the sign determines the direction.

This label construction is central to interpreting the results. Because the consensus-change value used to determine the label is present in the input, the classification is close to deterministic. The experiment therefore evaluates the model’s ability to execute a defined classification rule and produce structured outputs, rather than forecast future analyst behavior.

I construct the dataset from raw WRDS pulls using a PySpark bronze-silver-gold pipeline. The evaluation uses a random split with a fixed seed. QLoRA training runs in 4-bit on a single NVIDIA DGX Spark. I evaluate the base model and adapter using identical holdout events, prompts, nonthinking mode, and temperature zero.

The adapter achieves perfect accuracy and macro F1 on the holdout. However, aggregate scores alone obscure the mechanism responsible for this improvement.

The base model produces parseable responses for 466 of 1,000 events. Its positive and negative classifications are correct on all 447 of 447 calls for which it returns a direction.

Failures are concentrated in the neutral class. Of 351 neutral events, 332 produce unparseable responses. Of the remaining 19, 17 are classified as negative.

These findings indicate that fine-tuning primarily improves schema compliance and neutral-class handling. The improvement in aggregate accuracy should not be interpreted as a corresponding improvement in financial reasoning.

3. Training Scale and Generalization

I compare adapters trained on 1k and 10k events. Both achieve 1.000 holdout accuracy, while exact JSON match increases from 0.994 to 0.999.

I also evaluate both adapters on four public sentiment benchmarks, using 64 examples per benchmark.

4. Label Construction and Leakage Risk

Two methodological considerations limit the interpretation of the holdout results.

First, the directional label is derived from a consensus-change value already supplied to the model. This creates direct access to the information needed to recover the target. While appropriate for evaluating deterministic classification and structured-output reliability, it does not establish predictive performance on unseen future outcomes.

Second, the random event-level split does not explicitly isolate companies or chronological periods. Related revisions may therefore appear in both training and holdout data. This introduces a potential source of train-test contamination, although its effect on the reported results has not been quantified.

These limitations are distinct. The first concerns the relationship between input features and the target definition. The second concerns independence between training and evaluation observations.

5. Discussion and Future Work

The principal result is not simply that fine-tuning achieves perfect holdout accuracy. It is that error decomposition substantially changes the interpretation of that result.

The base model’s failures are dominated by invalid output formatting and neutral-class errors. Fine-tuning resolves these failures, but the deterministic label construction prevents the resulting accuracy from serving as evidence of forecasting ability.

Future evaluation should introduce company-held-out and chronological splits, a more challenging neutral-class definition, and independent magnitude evaluation. The base model should also be evaluated on the same public sentiment slices to establish a complete comparison.
